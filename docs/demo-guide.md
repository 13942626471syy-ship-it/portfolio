# 项目演示导览

按“问题 → 操作 → 可见产物 → 验证边界”的顺序看项目，避免只展示技术名词。

## WhiteGZ

1. [报告工作台](../assets/whitegz/report-workbench.png)：从经营指标进入章节和来源覆盖。
2. [证据检查](../assets/whitegz/evidence-review.png)：查看结论的支持状态及仍待核验的信息。
3. [图表编辑](../assets/whitegz/chart-lab.png)：调整标题、单位和数据，查看导出入口。

前两张是公开来源样本的历史本地回放；财务数字未在此次发布中重新核验，仅用于功能展示，不构成投资建议。图表使用合成演示数据。

## ISAD

1. [控制台](../assets/isad/modeling-console.png)：查看按需求、行为和对象建模组织的成果。
2. [BCE 分析](../assets/isad/bce-analysis.png)：拆分边界、控制和实体职责。画面仍有进度与警告，不表示全部语义验收完成。
3. [数据库设计](../assets/isad/database-design.png)：确认字段类型、主键与可空规则。
4. [实际顺序图](../assets/isad/design-sequence.png)：查看演示模型生成的主线交互产物。

使用隔离 QA 环境中的“作业提交与取消”演示模型，画面账号为验收用角色。图形生成成功不代表所有异常分支已验证。

## ERP Agent

1. [教学工作台](../assets/erp-agent/teaching-workbench.png)：查询模拟企业状态，区分问答和经营动作。
2. [连续追问](../assets/erp-agent/rule-followup.png)：在模拟贷款规则问题中保留参数与上下文。

图片来自学生助手独立演示界面，不能与规则/规划主工程混为同一个发行版本。资金是模拟数据，不代表真实资产或官方比赛成绩。

## 拾光盒子 CampusLoop

1. [闲置登记](../assets/campusloop/clearout.png)：描述品类、品相与收纳方式。
2. [组合包](../assets/campusloop/packages.png)：浏览开箱包和预约清单。
3. [运营台](../assets/campusloop/operations.png)：查看模拟流程与经营指标。

这是 MVP 业务演示。价格、库存、估价与转化率不代表真实交易或已验证的 AI 效果；没有接入真实支付或正式身份认证。
