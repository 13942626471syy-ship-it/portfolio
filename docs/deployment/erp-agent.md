# ERP Agent：主工程与学生助手

适用于已经获得对应源码或交付包授权的协作者。主工程与学生助手独立副本必须分别维护，不能混用目录、状态和验收记录。

## 规则与规划主工程

当前 `pyproject.toml` 要求 Python 3.12（`>=3.12,<3.13`），使用 uv、PostgreSQL、Qdrant 和 FastAPI。依赖以目标工程声明与锁文件为准。

在主工程根目录的开发环境执行：

```bash
uv sync --all-groups
docker compose up -d postgres qdrant
uv run alembic upgrade head
uv run uvicorn apps.api.main:app --host 127.0.0.1 --port 8000
```

数据库迁移需先确认专用开发库。不要将真实课堂状态或私人配置带入演示环境。服务启动后先检查 API 文档与 readiness，再运行需要数据库或证据检索的功能。

Windows PowerShell 可执行只读检查：

```powershell
curl.exe --fail http://127.0.0.1:8000/health
curl.exe --fail http://127.0.0.1:8000/api/readiness/classroom
```

`/health` 预期为 `{"status":"ok"}`。准备度接口报告环境和课堂确认条件，存在阻断项时按原因处理；HTTP 200 不能直接解释为可以开始完整经营或高分搜索。

## 学生助手独立入口

现有 Windows 启动器支持独立端口及离线模式：

```powershell
.\Start-StudentAssistant.ps1 -Offline -WebPort 3004 -ApiPort 8016
```

对应本机入口为 `http://127.0.0.1:3004/student`。先使用离线确定性功能；模型讲解需要另外具备授权配置。本公开仓库不提供任何凭据。

## 常见问题与更新

| 现象 | 检查方向 |
| --- | --- |
| uv 无法选择解释器 | 使用 Python 3.12，避免自动切换到不满足工程约束的版本 |
| HTTP 健康检查通过但准备度阻断 | 分别检查数据库、Qdrant 与未确认的课程条件 |
| 搜索超时或没有终局 | 保留停止原因、未覆盖域和失败诊断；不能据此断言全域无解 |
| 旧路线分数与当前运行不一致 | 固定源码、规则和起始条件，重新通过当前执行器独立回放 |

升级前保存私有配置、数据库备份和规则版本，演示副本使用单独状态。恢复旧版本时重新核对数据迁移与规则兼容性；不要直接续跑旧进程或把历史快照注入新搜索。
