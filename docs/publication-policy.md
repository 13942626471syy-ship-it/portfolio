# 公开范围与资料使用

## 本仓库公开什么

- 项目目标、功能范围与概括性技术结构。
- 当前状态、已知边界与经过整理的维护摘要。
- 已逐张审核、标明数据性质的演示截图与建模产物。

## 不公开什么

- 产品源码和内部仓库内容。
- 账号、密钥、访问令牌和部署配置。
- 真实数据库、业务记录、学生资料及联系方式。
- 原始聊天记录、内部工作日志、未审核的文档或截图。
- 未取得使用许可的第三方代码、素材或课程资料。

## 阅读与使用

这些资料用于项目展示。公开可阅读不表示产品源码已开源，也不表示第三方内容取得了额外授权。访问者应遵守适用版权和平台规则；项目的具体许可不在此作额外授予。
