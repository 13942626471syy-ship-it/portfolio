# DNUI · 党员成长积分管理系统

面向党员成长活动积分申报、审核与管理的校园业务工具。

## 项目范围

项目包含小程序、后端 API 和本地部署检查面板，用于组织校园业务页面、接口与维护流程。

## 技术与维护重点

后端采用 TypeScript / Express，并使用数据库、输入校验与身份验证相关组件。维护重点包括多用户流程、权限边界、业务记录一致性和部署检查。

## 隐私边界

不公开学校内部配置、学生身份、活动名单、积分明细、组织信息、管理入口或任何真实数据库。后续界面展示仅使用经过审核的虚构数据。

## 当前状态

持续维护。此页不宣称已通过最新完整验收，也不提供真实校园系统访问入口。
